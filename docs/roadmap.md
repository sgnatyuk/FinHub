# Roadmap

## Сделано

- Доменное ядро: `money`, `user`, `hub`, `category`, `expense`, `stats` с тестами (PR #1).

## Дальше

1. Postgres-адаптер: миграции goose, репозитории на pgx, интеграционные тесты, локальная база в Docker.
   Атомарно: создание хаба + владелец; удаление категории + перенос трат.
2. CI на GitHub Actions: `gofmt`, `go vet`, `go test`, golangci-lint.
3. `auth` + CLI: регистрация (пользователь + личный хаб + стартовые категории), токены, сессии, активный хаб.
4. Telegram-бот: привязка chat_id к пользователю, групповой чат к хабу.

## Потом

- Бюджет хаба на месяц (пакет `budget`), статистика показывает остаток.
- Доход (пакет `income`), если понадобится.
- Роли кроме owner/member.

## Открытые вопросы

- Как приглашать в хаб: код, ссылка в боте?
- Что видит участник после выхода из хаба (сейчас: его траты остаются в хабе).
