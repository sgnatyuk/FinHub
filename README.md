# FinHub

Трекер расходов на Go: общие хабы для семьи, категории и теги, статистика.
Бизнес-логика отделена от клиентов — CLI и Telegram-бот, хранение в PostgreSQL.

## Структура

```
internal/
  money/     суммы в минимальных единицах (int64), RUB и USD
  user/      владелец данных
  hub/       общий учёт трат: участники, роли, валюта, часовой пояс
  category/  категории хаба («на что потрачено»), одна на трату
  expense/   траты и теги («зачем, в каком контексте»)
  stats/     суммы по категориям, тегам, авторам и хабам
```

Пакеты ядра не знают о базе данных и клиентах: хранилище описано
интерфейсами `Repository` в пакетах-потребителях.
